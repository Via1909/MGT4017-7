# MGT4017 — BeautyLoop

Responsive BeautyLoop skincare website concept based on the supplied website design.

## Upload these files to the ROOT of your GitHub repository
- `index.html`
- `styles.css`
- `script.js`
- `assets/` (upload the entire folder, including all six JPG images)
- `README.md` (you may keep your existing GitHub README if you prefer)

**Important:** Keep the `assets` folder next to `index.html`. Do not upload the JPG images separately into the repository root, and do not rename the image files. The image links in the website use relative paths such as `assets/cloud-cream.jpg`.

## Publish with GitHub Pages
1. Open repository `MGT4017`.
2. Upload the files listed above so `index.html` is visible at the repository's top level.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish and use the website URL shown on the Pages settings screen.

## Website features
- Home page and product cards with images
- Refill & Return Rewards promotion
- Subscription plan cards
- Customer reviews
- My Account demo panel with Reset Plan
- Get in Touch contact form

## Demo limitations
The bag, subscription buttons, account panel and contact form are front-end demonstrations only. No checkout, payments, login, database or message delivery is connected. Product descriptions, prices, ingredients and reviews are illustrative student-project content.
